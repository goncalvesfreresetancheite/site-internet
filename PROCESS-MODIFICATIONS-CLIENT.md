## 🔄 Process de Traitement Interne

### **Étapes de traitement** :

1. **Réception** (J+0)
   - Accusé de réception sous 2h ouvrées
   - Vérification de la complétude de la demande
   
2. **Analyse** (J+0 à J+1)
   - Estimation du temps nécessaire
   - Identification des éventuels blocages techniques
   - Questions de clarification si nécessaire

3. **Développement** (selon priorité)
   - 🔴 Urgent : sous 24h
   - 🟠 Important : sous 3 jours
   - 🟢 Normal : sous 1 semaine

4. **Tests** (avant livraison)
   - Tests fonctionnels
   - Tests multi-navigateurs
   - Tests mobile/desktop
   - Validation des critères définis

5. **Livraison** (J final)
   - Notification au client
   - Documentation des modifications effectuées
   - Fichiers mis à jour (si nécessaire)

6. **Validation client** (J+1 à J+3)
   - Période de test client
   - Corrections mineures si besoin
   - Validation finale

## 🎓 Exemples de Demandes Bien Formulées

### **Exemple 1 : Modification de texte**

```markdown
**Nom du client** : GFE
**Page concernée** : Toutes les pages de réalisations
**Type** : Texte / Contenu
**Priorité** : 🟢 Normal

**Description** :
Remplacer "Nos Réalisations" par "Nos dernières réalisations" 
sur toutes les pages où ce titre apparaît.

**Localisation** :
- Section titre H2 des pages blog
- Bouton de navigation dans le header
- Lien dans le footer

**Résultat attendu** :
Le texte "Nos dernières réalisations" doit être affiché partout 
où "Nos Réalisations" était présent, avec la même mise en forme.

**Critères de validation** :
- Ctrl+F "Nos Réalisations" ne trouve plus aucune occurrence
- Le texte "Nos dernières réalisations" est présent et correctement formaté
```

### **Exemple 2 : Ajout de fonctionnalité**

```markdown
**Nom du client** : GFE
**Page concernée** : index.html - Formulaire de contact
**Type** : Fonctionnalité / Formulaire
**Priorité** : 🔴 Urgent

**Description** :
Le formulaire doit envoyer un email en FRANÇAIS (actuellement en anglais)
et inclure les pièces jointes uploadées par l'utilisateur.

**Problème actuel** :
- Email reçu en anglais avec headers anglais
- Pièces jointes non reçues dans l'email

**Résultat attendu** :
- Email reçu en français avec :
  - Objet : "Demande devis site 2 // [Nom] - [Ville]"
  - Contenu : Tous les champs du formulaire en français
  - Pièces jointes : Fichiers uploadés joints à l'email
- Destinataire : hello@agencedelombre.fr
- Copie cachée : gfe-etancheite@hotmail.com (à activer plus tard)

**Configuration souhaitée** :
- Service d'envoi : EmailJS ou équivalent supportant fichiers
- Limite fichiers : 10 Mo par fichier
- Formats acceptés : JPG, PNG, PDF

**Critères de validation** :
- Test d'envoi avec 1 fichier PDF : email reçu en français avec PJ
- Test d'envoi avec 3 images : email reçu avec les 3 images
- Objet email contient le nom et la ville saisis dans le formulaire
```

### **Exemple 3 : Correction de bug**

```markdown
**Nom du client** : GFE
**Page concernée** : index.html
**Type** : Bug / Correction
**Priorité** : 🔴 Urgent

**Description** :
Le site s'affiche entièrement blanc. Aucun contenu n'est visible.

**Contexte** :
Après l'ajout des animations au scroll, le site ne s'affiche plus.

**Étapes pour reproduire** :
1. Ouvrir index.html dans Chrome
2. La page charge mais reste blanche
3. Console : "Identifier 'observerOptions' has already been declared"

**Résultat attendu** :
- Le site s'affiche normalement
- Toutes les sections sont visibles
- Animations fonctionnent au scroll

**Critères de validation** :
- Aucune erreur dans la console
- Toutes les sections sont visibles
- Animations se déclenchent au scroll
```

## 💡 Bonnes Pratiques

### **DO ✅**
- ✅ Être précis et détaillé

- ❌ Pas de contexte ou d'explication
- ❌ Références manquantes ("comme sur l'autre site")
