## 🌍 ÉTAPE SUIVANTE : Mettre le site en ligne

Une fois sur GitHub, déployez sur **Cloudflare Pages** (gratuit, rapide, CDN mondial) :

1. Allez sur [dash.cloudflare.com](https://dash.cloudflare.com/)
2. Pages → "Create a project"
3. "Connect to Git" → Sélectionnez `gfe-etancheite`
4. Laissez les paramètres par défaut
5. "Save and Deploy"

**Votre site sera en ligne en 2 minutes sur :**
```
https://gfe-etancheite.pages.dev
```

Ensuite, ajoutez votre domaine custom :
```
www.goncalves-freres-etancheite.fr
```

**Détails complets dans :** `DEPLOYMENT.md`
